## 二、目录结构速查（2026-09-11 整理；2026-09-20 更新路径与例数）

```
F:\edu-agent3\
├─ README.md  CHANGELOG.md  CONTRIBUTING.md   # 顶层只留这 3 个 md
├─ requirements.txt  .env.example  .gitignore
├─ 启动课本教练.bat                            # 顶层唯一启动入口（双击即可）
├─ deploy/          # 启动/停止脚本：start_ui.cmd、start_web.cmd、stop_ui.cmd、run_ui.ps1
├─ src/edu_agent/   # 应用代码（29 个模块）
├─ static/          # 前端：index.html + vendor/（marked / purify / mammoth / pptxgenjs 本地兜底）
├─ tests/           # 测试（298 例；296 通过、2 例真实 WPS 联调按环境跳过）
├─ scripts/         # 运维与一次性脚本：clean_corpus.py、repair_fm.py、smoke_test.py、backfill_chunk_meta.py、build_toc_ranges.py
├─ docs/            # 全部文档（00~18，见上表）
├─ eval/            # 评测脚本与存档（golden_questions / s9_results / demo 兜底）
├─ content/         # 教材文本源（structured_auto 入库；plans/raw 本地）
├─ chroma_db/       # 预建向量库（edu_textbook 151 块 + edu_wiki，二进制，单人负责）
├─ legacy/          # 归档（旧 Gradio 版），只读不再改
├─ mcp_servers/     # MCP 工具服务（当前只有 math_server.py）
└─ data/ logs/ model_cache/ .venv/ .uv-cache/  # 运行时与缓存（不入库）
```
