## 3. 详细设计

### 3.1 后端（+77 / −1，纯增量）

**① 新 skill：`doc-session-preview`**（`capabilities.py`）

```python
SkillSpec(id="doc-session-preview", name="会话文档预览", icon="D",
          desc="AI 生成文档后，在会话页右侧唤起多格式预览面板（内存渲染，不落盘、不调用 WPS）",
          category="文档", builtin=True)
```

- `SkillSpec` 新增 `builtin`：内置能力（无 `skills/<id>/SKILL.md`），UI 显示「内置」而非「文件缺失」；
- 不绑 MCP → 不因关 WPS 而显示「依赖已关」；
- 新增 `capabilities.session_preview_ready()`；`snapshot()` 增 `session_doc_preview_ready` 与每项 `builtin`。

**② 新接口 `POST /api/session/doc-preview`**（`web_server.py`）

```jsonc
// 请求：markdown 留空时会话里最近一份教案兜底
{"payload": {...}, "markdown": "文本", "session_id": "…"}
// 响应（输入原样回传 + 派生预览模型）
{"ok": true, "enabled": true, "title": "3.3 幂函数",
 "markdown": "…", "payload": {...},
 "blocks": [{"title":"教学目标","level":2,"chars":43}],
 "slides": [{"name":"情境导入","minutes":"5","bullets":["…"]}],
 "stats": {"chars":222,"blocks":9,"slides":3,"minutes":20},
 "note": "内存预览：不落盘、不调用 WPS；需要落盘请走 /api/wps/export"}
```

- **无磁盘 IO**：只用 `wps_export.slides_from_markdown()`（纯计算）与 `_plan_blocks()`（纯文本处理）；
- **不查 WPS 开关**，也**不在接口层加闸门**——纯函数，开关只影响前端渲不渲染。

**③ `GET /api/mcp/status`** 增 `session_doc_preview_ready`。
**④ 明确未改**：`wps_export.py`、`/api/wps/*`、`mcp_tools.py`、`deploy/*`、安装脚本、`.gitignore` 护栏、`/api/template/*`。

### 3.2 前端预览面板

```html
<aside id="docPanel">                     <!-- 全局层，任何页面都能看到 -->
  <div id="docPanelGrip"></div>           <!-- 左边缘拖拽调宽；双击复位 460 -->
  <input type="file" id="docPanelFile" accept=".docx">   <!-- 隐藏；右下角入口用它 -->
  .dp-hd   标题 + 字数·页数 + [下载▾] [位置] [×]
  .dp-tabs 文档 | Markdown | 幻灯片 | 结构
  #docPanelBody / #docPanelRes
</aside>
<button id="docPanelFab">导入/查看/收起文档</button>       <!-- 右下角常驻 -->
```

| 项 | 设计 |
|---|---|
| 自动唤起 | `done` 分支：`ev.mode==='B'` 或 `ev.html` 或正文含 `Agent B` → `docpFromAnswer()` |
| 开关闸门 | 以**接口返回的 `enabled`** 为准（服务端唯一真相源）；不先等 `capLoad()`（否则首屏 WPS 桥接探测会拖慢数秒） |
| 历史恢复 | **不自动弹面板**（避免盖住会话）；调 `docpArm()` 备好并**点亮右下角入口** |
| 拖拽调宽 | 320 ~ min(920,74vw)，存 `localStorage: edu_docpanel_w`，双击复位 |
| 让位 | 打开时给 `body` 加 `.dp-open`；会话页消息区与教案中心都按 `--docp-w` 让出右侧 |
| 两种来源 | 会话教案（Markdown：四页签全开，下载走 `markdown:`）；导入的 .docx（富结构：文档逐 run 渲染含真表格，下载走 `template:` 原格式直出） |
| 下载合并 | 原 Word/PPT/HTML 三钮 → 一个 `下载 ▾`，**悬停弹出菜单**（点击也能开，选完自动收起） |
| 前置校验 | WPS 未就绪 → 菜单落盘两项**灰显但仍可点**（点了说明原因）；HTML 不受影响；编排台的「导出 Word · WPS」同步置灰 |

## 4. 关键取舍

| # | 取舍 | 选择 | 理由 |
|---|---|---|---|
| 1 | 模板与教案中心怎么处理？ | **只删模板编辑器**；页面/编排台/导入保留 | 你最终口径：「教案中心不是让你删掉，而是让教案中心的教案编辑删除」 |
| 2 | 预览要不要受 WPS 开关控制？ | **不受**，只看自己的 skill 开关 | 要求「严格区分」；关 WPS 只是想停落盘，不该连带看不了稿 |
| 3 | 预览接口要不要加服务端闸门？ | **不加** | 纯函数无副作用；加了反而让「关预览」可能影响别的调用 |
| 4 | 「可拖拽」怎么理解？ | 拖左边缘调宽（+ 双击复位、宽度记忆） | 侧边面板通行做法，比漂浮窗稳、不遮内容 |
| 5 | 三个下载按钮怎么收？ | 合并成 `下载 ▾` + 悬停菜单 | 面板最窄 320px，三钮会挤 |
| 6 | 关掉面板/刷新后怎么再看？ | **右下角常驻入口**（导入/查看/收起） | 原设计关掉就找不回来；空态还能直接导入，解决"想导入却没入口" |
| 7 | 面板挂在哪一层？ | **全局层**（不在 `#view-chat` 内） | 否则在教案中心导入后看不到结果 |
