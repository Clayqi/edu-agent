# 幻灯片可编辑 + 可导入模板 计划书（v1.16.0 拟）

> 老师原话：「我要的是在**幻灯片这一页显示的预览页可以编辑**，并且**直接显示的是合适的风格、排版**，
> 而不是要下载、导入进行优化」→ 随后拍板四项：
> ① **PPT 优化按钮挪到「文档」页签的合适位置**（不再占幻灯片页签顶部）；
> ② **版式 6 个**；③ **主题做成可导入模板**；④ **会话生成的内容可以用来替换模板的文字**。
>
> 本文只写计划。文末 §12 是还需要你点头的小项。

---

## 0. 一句话

**幻灯片页签 = 面板内的幻灯片编辑器**：点开就是一套像样的版式与排版（默认就好看），
**页内直接改**（标题/要点/页序/时长/版式），**风格来自模板**（内置 3 套 + 你导入的学校/品牌 `.pptx` 模板），
**会话里生成的内容自动填进模板的文字槽**；改完的这份就是导出的那份。

---

## 1. 目标 / 非目标

**目标（一期）**

1. 幻灯片页签里的**每一页都能直接编辑**（标题、要点、页序、时长、版式），改完立即看到；
2. **默认排版就像样**：6 个版式 + 一套写死的排版规范（字号阶梯、边距、行距、一页一主色、页码）；
3. **风格可换、可导入**：内置 3 套主题即"内置模板"；可导入自己的 `.pptx` 当模板（读它的配色/字体/母版/文字槽）；
4. **会话内容替换模板文字**：把会话里那份教案演化出的 slides 填进模板的文字槽，产出**保留母版与版式**的 pptx；
5. 改过的幻灯片**能带走**：存进会话（刷新/切会话还在）、导出 PPT 用的就是它；
6. 全程**不依赖模型**（版式与填充都是确定性规则），AI 只留到三期做"选版式/精简措辞"。

**非目标**

- 不做"导入旧稿 → 全局重排/美化"（那是 `docs/17` 那条线，保留但降级到「文档」页签的"高级"里）；
- 不在面板里做像素级自由排版（拖任意元素、改坐标）—— 这是"教师做的演示稿"，不是设计工具；
- 不动教案正文与 Word 导出那条链路（教案以 Markdown 为准）。

## 2. 现状与两处**必须改**的技术点

现状（已核实）：

- 幻灯片页签是**只读**的：`docpBuildDeck()` 用 pptxgenjs 在内存里建 deck（封面 + 每环节一页），
  `docpRenderSlides()` 渲染 16:9 卡片 + 页卡；样式是临时的深蓝底白字列点；
- `slides` 是**每次从教案 Markdown 现算**的（后端 `wps_export.slides_from_markdown`）；
- 导出 PPT 走 `/api/wps/export` → `_export_pptx()` → **`steps = payload.get("steps")`**（`wps_export.py`）。

**必须改的两处**（不改的话"改了也白改"）：

| # | 问题 | 改法 |
|---|---|---|
| 1 | 手工改的幻灯片带不进导出：前端 `docpExport()` 只发 `{markdown, kind}`，后端于是从 Markdown 重新派生 | 导出时发 **`payload.steps`**（每页 `{name, minutes, bullets, layout, …}`）；后端已支持，`pptx_native()` 直接吃 |
| 2 | 改了会被下一次派生覆盖 | slides 提升为**会话里的一等数据**：写进 `meta.doc.slides`（与现有 `meta.doc` 同一机制），并加"已被手动调整"标记 |

## 3. 幻灯片编辑器（页签内的交互）

### 3.1 编辑能力（最小集）

| 能改 | 交互 | 落点 |
|---|---|---|
| 标题 / 要点文字 | 卡片内 `contenteditable` 直接改（与「文档」页签同一套习惯） | `slides[i].name` / `slides[i].bullets[]` |
| 加 / 删要点 | 卡片内 `＋ 要点` / 每条右侧 `×` | 同上 |
| 加 / 删页 | 底部 `＋ 新页`；页右上 `×` | `slides[]` |
| 换页序 | 页卡拖拽排序 | `slides[]` 顺序 |
| 每页时长 | 卡片角上 `约 __ 分钟` | `slides[i].minutes` |
| 换版式 | 每页右上角下拉（6 选 1） | `slides[i].layout` |
| 换风格 | 页签顶部下拉：模板（内置 3 + 导入的 N） | `payload.template_id` |

**即时反馈**：改完立刻按当前版式/模板重绘该页；**不重绘正在编辑的那一页**（否则光标跳 —— 这条在「文档」页签已经踩过）。

### 3.2 版式 6 个（首批，含"槽位"定义）

每个版式声明自己有哪些**槽（slot）**；编辑器和"内容填模板"都按槽工作，这样模板与版式是同一套抽象。

| 版式 id | 名字 | 槽 | 用途 / 规则 |
|---|---|---|---|
| `cover` | 封面 | `title` `subtitle` `meta`(课题/学情/课时) | 第 1 页；主标题 40pt 左对齐 + 主色细线 |
| `section` | 章节过渡 | `index` `title` | 环节切换；大号序号 + 环节名 32pt，整页大留白 |
| `bullets` | 要点页 | `title` `bullets[]` | 主体；**每页 ≤6 条、每条 ≤22 字**，超了给"拆页"提示 |
| `two-col` | 两栏 | `title` `left{heading,bullets[]}` `right{heading,bullets[]}` | 对比/并列；栏间距 48px |
| `media` | 图文 | `title` `image` `caption` `bullets[]` | 有图/有表；图 55% 宽，注释 15pt |
| `end` | 结尾 | `title` `bullets[]` `closing` | 小结 3 条 + 一句话收束 |

（`slides_from_markdown()` 派生的初始版式规则：第 1 页 → `cover`，其余 → `bullets`，最后一页 → `end`；
带"约 X 分钟"的环节名 → 可一键转 `section`。）

### 3.3 排版规范（写死成默认值，保证"一打开就像样"）

- 画布 **1280×720**；**安全边距 64px**，内容区 1152×592；
- 字号阶梯：**封面主标 40 / 页标题 32 / 正文 22 / 注释 15**；行距 1.35；段间距 = 字号的 0.6；
- **一页只用一个主色做强调**（主色只出现在细线、序号、关键词）；其余走灰阶；
- 一律**左对齐 + 统一基线**（封面可选居中）；右下角**页码 x/N**；
- 三条内容规则：**每页 ≤6 条 / 每条 ≤22 字 / 一页只讲一件事**（超出给黄色提示，**绝不截断加省略号**）。

## 4. 模板体系：**主题 = 可导入模板**

把"主题"和"模板"合成一个东西：**模板决定风格（配色/字体/字号/母版/版式），内容由会话给**。

### 4.1 模板库（与教案模板同构）

```
content/ppt_templates/
├─ index.json                 # 模板清单（id / name / 来源 / 页数 / 版式集 / 是否内置）
├─ _builtin/                  # 内置 3 套（就是上面那 3 个主题，纯 JSON，不需要原稿）
│   ├─ academic-blue.json     #   学术蓝
│   ├─ clean-gray.json        #   简洁灰
│   └─ warm-class.json        #   课件暖
└─ <id>/                      # 用户导入的模板
    ├─ template.pptx          #   原稿（只读，永不改写）
    ├─ theme.json             #   抽出来的：配色 / 字体（latin+ea）/ 字号层级 / 母版与版式清单
    └─ slots.json             #   抽出来的：每页的文本槽（角色、容量、几何）
```

- **一份模板描述**（内置与导入统一形状）：
  `{id, name, kind: "json"|"pptx", theme: {palette, fonts, sizes}, layouts: [...], slides: [{index, layout, slots: [{role, capacity, geo}]}]}`；
- 内置 3 套就是 `kind: "json"` 的模板（只有 theme + 我们的 6 个版式），
  导入的 `.pptx` 是 `kind: "pptx"`（自带母版与版式，填充时**按它的页来**，视觉与学校模板一致）。

### 4.2 导入一份 `.pptx` 当模板（二期）

- 抽取用 **ppt-master 的 `pptx_template_import.py`**（已验证存在）：它保留 Master/Layout 继承链与文本槽，
  正是"套学校模板"需要的东西；配色/字体/字号再由 `beautify_identity.py`/`pptx_intake.py` 给出；
- 抽完写 `theme.json` + `slots.json` + 存 `template.pptx`（原稿只读），**不写模板库以外的任何地方**；
- 面板里：幻灯片页签顶部下拉出现这个模板；导出时走"填充"（§5）。

### 4.3 与「教案模板」（.docx）的关系

两套模板**并列不混**：`.docx` 模板管教案正文排版（`content/templates/`，已有），
`.pptx` 模板管演示风格（`content/ppt_templates/`，本次新增）。面板上分别标注"教案模板 / 演示模板"。

## 5. 会话内容 → 替换模板文字（填充器）

**输入**：会话里当前的 slides（§3 编辑后的那份）+ 选中的模板。
**输出**：保留模板母版/版式的 `.pptx`，文字是会话内容。

### 5.1 映射规则（确定性）

| slides 里的东西 | 填到模板的哪 | 规则 |
|---|---|---|
| 封面页 `title/subtitle/meta` | 模板的 `cover` 页槽 | 按角色匹配；模板没有封面页 → 用第一张内容页，**不硬造封面** |
| 每页 `name` | 该页的 `title` 槽 | 逐页顺序对应 |
| 每页 `bullets[]` | 该页的 `bullets` 槽 | 按容量装；装不下 → **提示拆页**，不截断 |
| 页 `minutes` | 模板的页脚/时间槽（有则填） | 没有就不填 |
| 想插章节页 | 模板的 `section` 页 | 只在你手动把某页设为 `section` 时生成 |

### 5.2 页数不匹配怎么办

| 情况 | 做法 |
|---|---|
| slides 页数 **多于** 模板内容页 | **复制模板自己的"内容页"版式**生成新页（母版继承不变，视觉仍是这套模板） |
| 少于 | 按你的选择：① 留空页（保页数）② 删掉多余页（**默认**） |
| 模板有封面/结尾、slides 没有 | 只填能填的，**不硬造**（沿用 ppt-master 的"模板有什么角色用什么角色"） |

### 5.3 填完必须过两道校验

1. **内容零丢失**：`beautify_inventory.py --verify`（逐页逐串，缺一个即失败）—— 已有能力，直接复用；
2. **容量自查**：把每个槽的"每行字数 × 行数"与填入文字比对，超出的页**列出来**（黄色提示，不阻断），
   因为 ppt-master 的出框检测只在 SVG 域，pptx 侧我们用模板容量数据自查。

- **移出幻灯片页签顶部**，改为放在**「文档」页签底部**、正文之后的一条**可折叠"高级"区**：

- 结果条（`#docPanelRes`）继续共用 —— 优化结果与填充结果都显示在那里。

## 7. 接口与数据

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/ppt/templates` | 模板清单（内置 + 导入） |
| `POST` | `/api/ppt/template/import` | 上传 `.pptx` → 抽 theme/slots → 存模板（二期） |
| `POST` | `/api/ppt/template/delete` | 删模板（软删到 `_trash/`，与教案模板同策略） |
| `POST` | `/api/ppt/fill` | `{slides, template_id, on_missing_pages}` → 生成 pptx（走 §5 填充器）→ 返回任务/文件 |
| `GET` | `/api/ppt/status` | 已有；**加** `templates_ready` 与当前模板 id |
| — | `/api/session/doc-preview` | 已有；**扩展** `payload.slides` 原样回传并**写进 `meta.doc`** |
| — | `/api/wps/export` | **不改行为**；前端改成发 `payload.steps`（§2 的技术点 1） |

**会话里的数据形状**（`meta.doc` 里新增，向后兼容）：

```jsonc
{
  "title": "3.3 幂函数",
  "markdown": "…",                    // 教案正文（Word 导出仍以它为准）
  "slides": [                          // ← 新增：一等数据，面板里编辑的就是它
    {"name":"3.3 幂函数","layout":"cover","minutes":"","bullets":[]},
    {"name":"情境导入","layout":"section","minutes":"5","bullets":["投影五个实例"]},
    {"name":"幂函数的概念","layout":"bullets","minutes":"12","bullets":["形如 y=x^α","α 为常数"]},
    {"name":"小结","layout":"end","minutes":"3","bullets":["三条结论"]}
  ],
  "slides_edited": true,               // 手动改过 → 重出教案时提示，不静默覆盖
  "ppt_template_id": "academic-blue"
}
```

## 8. 红线与落盘

- **预览不落盘**：编辑只改内存 + 会话 `meta.doc`（+ localStorage 镜像，沿用现有机制）；
- **模板文件**：`content/ppt_templates/` 是**用户资产**（原稿只读、软删进 `_trash/`）；
  建议 `.gitignore` 掉导入的原稿与 `index.json` 的运行态，仓库里只留内置 3 套 + 目录说明；
- **导出仍走 `/api/wps/export`**（行为不变）；填充器产物与优化产物都落 `data/ppt_out/`；
- `content/plans/` 与教案模板链路**不动**。

## 11. 风险与回退

| 风险 | 对策 |
|---|---|
| 幻灯片与教案正文"不同步" | 明确分工：**教案管 Word、幻灯片管 PPT**；面板标"已手动调整"；重出教案时**问**一声（保留/重置） |
| 模板版式与内容不匹配（槽太少/太多） | 页数不匹配按 §5.2；槽不够 → 复制内容页；**不硬造封面/结尾** |
| 导入复杂模板抽不出槽 | 抽取失败就退化为"只用它的主题（配色/字体/字号）"，页面仍用我们的 6 个版式，并在面板说明 |
| 编辑冲突（Agent 又出稿） | `slides_edited` 标记 + 确认弹窗；不静默覆盖 |
| 6 个版式不够用 | 版式表是数据（`layouts` 数组），加版式=加一条，不用改渲染骨架 |
