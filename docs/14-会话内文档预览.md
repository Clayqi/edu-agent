# 会话内文档预览（v1.14.0 · 2026-09-20）

**AI 生成文档后，会话页右侧的「侧边面板」自动切到「文档」视图：预览、编辑、下载都在这块面板里。**
看稿和改稿在会话里完成；要交出去的 .docx / .pptx 再点面板上的导出按钮落盘。

> 与 `docs/08-WPS集成说明.md` 的分工：08 讲 **WPS 落盘导出**（能力开关、COM、桥接补丁、坑）；
> 本文讲**会话内内存预览 + 编辑**（面板、四页签、开关）。两条链路严格分开，见 §1。
> 计划书与每一轮的改动记录见 `docs/16-侧边面板多格式渲染计划书.md`（§5.4~§5.8 是 2026-09-19/20 的四轮反馈改动）。

---

## 1. 两条链路（本改造的核心约束）

| | **会话内内存预览** | **WPS 落盘导出** |
|---|---|---|
| 目的 | 生成完就能看 | 拿到能交出去的文件 |
| 触发 | AI 出文档后自动唤起；也可点标题栏按钮切换页签 | 点面板上的 `Word` / `PPT` |
| 接口 | `POST /api/session/doc-preview` | `POST /api/wps/export` + `GET /api/wps/download` |
| 磁盘 | **不写任何文件** | 写 `content/plans/` 或自选目录 |
| WPS | **不调用、不查 WPS 开关** | 依赖 `wps-office` MCP（关掉即拒） |
| 能力开关 | `skill: doc-session-preview`（只管面板渲不渲染） | `mcp: wps-office` |

**双向解耦**（`tests/test_wps_tools.py::TestSessionDocPreview` 有用例锁住）：

- 关掉 **WPS** → 预览照常可用；点导出在**发请求前**就被拦下，并明说原因；
- 关掉 **会话预览** → 面板不渲染；`/api/wps/export` 行为一字不变。

## 2. 界面

**面板就是应用自带的右侧「侧边面板」（`aside#sidePanel`）** —— 会话页右侧只有这一块，没有第二块浮层：

```
.shell（窗口主体）
├─ aside.sidebar        左：导航
├─ main.main            中：各视图（会话 / 教案中心 / …）
└─ aside#sidePanel      右：侧边面板（300px；文档视图下自动加宽到 --docp-w）
   ├─ 标题行「侧边面板」 + [收起/展开]   ← 收起上面那排按钮
   ├─ 圆钮：状态 | 引用 | 知识源 | 会话 | **文档**（有文档时带角标）
   └─ #spBody ← 各视图内容；「文档」视图渲染：
      ├─ 标题 / 字数·页数 + [导入] [下载▾] [位置]
      │   └─ 鼠标悬停「下载」→ 弹出下载方式菜单（点击也能开，兼容触屏）
      ├─ 页签：文档 | Markdown | 幻灯片 | 结构
      ├─ 编辑工具栏（只在「文档」页签）：B / I / H2 / H3 / • 列表 / 1. 列表 / 清格式
      ├─ #docPanelBody：内容区（文档页签 = 可直接编辑）
      └─ #docPanelRes：下载结果条（文件名 + 目录 + 「下载到本机」）
```

进来 / 离开：**会话里每条回答操作行的【生成文档】**、Agent 出稿自动切到该视图、或直接点那个「文档」圆钮；
整块面板的开合由标题栏原有的**「侧边面板」按钮**管（左下角那个方框图标）。

面板支持**两种文档来源**，页签内容随之适配：

| 来源 | 进入方式 | 文档 | Markdown | 幻灯片 | 结构 | 下载走哪条 |
|---|---|---|---|---|---|---|
| **会话教案**（Markdown） | AI 出教案后自动切到文档视图 | ✅ 排版渲染，**可编辑** | ✅ 可编辑源码 | ✅ 每环节一页 16:9 | ✅ | `markdown:` → WPS |
| **导入的 .docx** | 面板里的「导入」/ 教案中心「导入 .docx」 | ✅ 逐 run 保格式（含真表格），**可编辑** | 改过后才有（编辑会生成 md） | —（按板块标题成页） | ✅ | 未改动：`template:` 原格式直出；改动后：`markdown:` |

| 页签 | 内容 |
|---|---|
| **文档** | `marked` + `DOMPurify` 渲染的类 Word 排版（`.dp-word`）；导入的 .docx 走 `mammoth` 转 HTML。**正文 `contenteditable`，可以直接改** |
| **Markdown** | **可编辑源码框**（`textarea`）；改完自动回流到「文档」「幻灯片」与导出 |
| **幻灯片** | 顶部**面板内 16:9 预览台**（上一页/下一页 + 页卡跳页 + 当前页高亮）+ 逐页卡片；`pptxgenjs` 只在内存里建 deck |
| **结构** | 板块清单 + 每块字数 + 「原始 JSON」折叠 |

**编辑（v1.14.0 新增）**：文档页签改完 400ms 防抖 → 转回 Markdown → `POST /api/session/doc-preview`（纯内存）
重算板块 / 幻灯片 / 统计 / 标题；**正在编辑的页签不重渲染**（光标不跳），其他页签跟着刷新；
**导出用改后的内容**（Word/PPT 走原链路；HTML 若改过则在浏览器内存里现生成下载）；
改动镜像到 `localStorage: edu_docp_edit_v1|<会话>|<标题>`，刷新/切视图不丢（只在原文未变时恢复）。

标题栏按钮（**下载出口已合并成一个**）：

| 按钮 | 行为 |
|---|---|
| **导入** | 选一个 `.docx` → 服务端解析成富结构 → **只在面板里预览 / 编辑 / 下载**（不建模板、不进模板库） |
| **下载 ▾** | **鼠标悬停弹出下载方式菜单**，三选一：<br>· **Word（.docx）** 经 WPS 导出 · 落盘<br>· **PPT（.pptx）** 本地生成 · 每环节一页<br>· **HTML** 网页版 · 直接下载（未改动时取服务端那份；改过则面板内现生成）<br>落盘的两项在 `wps-office` 未就绪时**灰显**，但**仍可点**——点了会在结果条里说明原因 |
| **位置** | 选择导出目录（记忆 `edu_dz_outdir`） |
| **收起 / 展开**（面板右上角） | 收起上面那排圆钮，把高度让给文档（状态记忆 `edu_sp_quad_collapsed`；文档视图默认收起） |

**拖拽调宽**：按住面板左边缘拖动（`#docPanelGrip`），宽度夹在 360 ~ min(1000, 80vw)，双击复位 **680**（默认宽）。

## 3. 接口

### `POST /api/session/doc-preview`

纯内存：**不落盘、不调用 WPS MCP、不查 WPS 能力开关**；输入原样回传 + 派生预览模型。

```jsonc
// 请求
{"payload": {...}, "markdown": "文本", "session_id": "…"}   // markdown 留空时会话里最近一份教案兜底
// 响应
{"ok": true,
 "enabled": true,                 // = skill 开关 doc-session-preview，前端据此决定渲不渲染
 "title": "3.3 幂函数",
 "markdown": "…",                 // 原样回传
 "payload": {...},                // 原样回传
 "blocks": [{"title": "教学目标", "level": 2, "chars": 43}],
 "slides": [{"name": "情境导入", "minutes": "5", "bullets": ["…"]}],
 "stats": {"chars": 222, "blocks": 9, "slides": 3, "minutes": 20},
 "note": "内存预览：不落盘、不调用 WPS；需要落盘请走 /api/wps/export"}
```

> 刻意**不在接口层加闸门**：接口是纯函数，关掉开关只影响前端渲不渲染（响应里的 `enabled=false`）。
> 这样「关掉预览」不会连带影响任何导出调用。

### `GET /api/mcp/status`（改动）

新增字段 `session_doc_preview_ready`（= `skill: doc-session-preview` 开关状态）；
`GET /api/capabilities` 的快照里同样带这个字段。

## 4. 能力开关

新增 **skill**：`doc-session-preview`（名称「会话文档预览」），**默认开启**，在 **Skill 市场**里可开关。

- 它是**内置能力**（没有 `skills/<id>/SKILL.md` 实体），`snapshot()` 里带 `builtin: true`，
  UI 显示「内置」而不是「文件缺失」；
- 不绑定任何 MCP 服务，所以不会因为关掉 WPS 而显示「依赖已关」；
- 关掉后：会话页**不渲染**右侧面板，导出链路**完全不受影响**。

## 5. 教案中心：页面保留，只移除了「模板编辑器」

「教案中心」页面（导航项 `design`）与 **教案 × PPT 编排台** **完整保留**，不再改动；
本次只从里面移除了**模板编辑器**这一块：

| 教案中心页面里的东西 | 处置 |
|---|---|
| 教案 × PPT 编排台（课题/学情、生成骨架、＋添加环节、保存、导出 HTML、预览 PPT、导出 Word·WPS、生成 PPT·WPS、导出位置；两栏编辑器） | **保留**（原样） |
| **导入 .docx** | **保留**（模板行里现在只有它） |
| 模板下拉 / 载入编辑 / 新建空白 / 删除 / 保存为模板 / 退出模板模式 / 格式工具栏 / 模板编辑器 | **移除** |

**「导入 .docx」的行为**：解析成富结构后**只进侧边面板的「文档」视图**（看 + 改 + 下载；未改动时下载走 `template:` 按原格式直出），
**不写入模板库**。面板现在是窗口骨架的一级子元素（`.shell` 里、`main` 之后），所以在教案中心导入也能**就地**看到。

**边界**（照实说）：

- 后端 `/api/template/*` 一行未动，`content/templates/` 里的模板文件也**没删**；
- 前端**不再有**「把 .docx 导入成模板 / 编辑板块·段落·格式 / 另存为模板 / 删除模板」的入口
  （注意区分：**面板里的文档编辑**是改这份文档用于导出，不写模板库）；
- 「① 生成教案模板」（后端生成并落库）与「② 按模板生成」（Agent B 套用所选模板）**后端仍然可用**，
  但**会话里已经没有这张「下一步」卡片了**（2026-09-19 去掉，见 `docs/16-…计划书.md` §5.5），
  所以这三个按钮在界面上没有入口，教案模板相关操作从**教案中心**走；
- 「③ 填入」的实现仍在（结果进右侧预览面板），同样随卡片一起不再出现在会话里。

另外：对话里原先挂在回答下方的「导出条」已移除，改由预览面板承担（避免两处入口）。

**入口就一个：侧边面板里的「文档」圆钮**（有文档时带角标）：

| 状态 | 表现 | 点击行为 |
|---|---|---|
| 还没有文档 | 圆钮无角标；该视图显示空态（提示问一句教案，或点【导入】） | 切到「文档」视图 |
| 有文档、当前不在该视图 | 圆钮带角标 | 切过去并渲染当前文档 |
| 已在文档视图 | 圆钮高亮 | 保持（整块面板的开合在标题栏那个「侧边面板」按钮上） |

会话侧另有**每条回答的【生成文档】**：把该条回答（含答疑）送进面板并自动切到文档视图 —— 这是会话 → 面板的唯一入口；
同一条重复点只开面板、不重复请求（结果挂在 `el.__doc` 上）。

## 6. 测试

| 文件 | 例数 | 覆盖 |
|---|---|---|
| `tests/test_wps_tools.py` | 34 | 原 25 例 + `TestSessionDocPreview` 9 例：能力在册且为内置 / 状态字段 / **纯函数（不落盘、不调 MCP）** / 原样回传 / **WPS 关掉预览照常** / **预览关掉导出照常** / 状态接口字段 / **Agent 标签剥离** / **历史 `meta.doc` 清洗** |

jsdom 真 DOM 回归（临时脚本，不入库）**6 组场景**，全过：

1. **A**：每条回答（含答疑）操作行都有【生成文档】；点一次 1 个请求、再点 0 个请求（不重复请求）；
2. **B**：四个页签各自的渲染器 —— 文档页签真调 `marked` + `DOMPurify`（渲染出 h1/ul）且**可编辑 + 工具栏显示**；
   Markdown 页签是**可编辑源码框**；幻灯片真调 `pptxgenjs`（**无 `writeFile`**）+ 面板内 16:9 预览台；结构页签有「原始 JSON」折叠；
3. **C**：4 个库全 404（harness 用 `requestInterceptor` 拦）→ 文档页签仍出内容、仍可编辑、幻灯片仍成页，零运行时错误；
4. **D**：后端照旧下发 `options`，但会话里**不再渲染**「下一步」卡片（0 张卡 / 0 个 `[data-plan]` 按钮 / 设置里也无那行开关）；
5. **E**：关掉「会话文档预览」→ 不进文档视图、【生成文档】置灰；关掉 WPS → 预览照常、导出**前置拦下（0 个请求）**；
6. **F**：`.shell` 右侧只有一块面板；点「文档」圆钮进文档视图；Agent 出稿自动切过去；面板内改正文 → 1 次回流 →
   Markdown 同步 → localStorage 有镜像 → 切走再切回改动还在。

另有一条**真数据探针**：旧会话（正文带 `**【Agent B · 教案 Agent】**` 标签）点开面板，标题取到真标题、四页签无标签。

全量：**217 例通过**（skipped=2 为需真 WPS 的用例）。

## 7. 排错

| 现象 | 原因 / 处理 |
|---|---|
| AI 出了文档但右侧面板没内容 | ① 设置里「会话文档预览」被关了（Skill 市场可开）；② 该回答不是文档类（只有 Agent B 出的教案会自动切到文档视图）；③ 面板本身被标题栏的「侧边面板」按钮关掉了。都不是的话，会话里点该条回答的【生成文档】 |
| 面板挡住消息 / 文档区太小 | 面板左边缘拖动调宽（夹在 360 ~ min(1000, 80vw)，双击复位 680）；上面那排圆钮点右上角「收起」折叠，高度全给文档 |
| 「下载」按钮上悬停没反应 | 菜单是 CSS `:hover` 弹出的，鼠标要停在按钮上；触屏/点击也能开（再点一次收起） |
| 下载菜单里 Word/PPT 是灰的 | `wps-office` 服务未就绪 → 去「MCP 服务」开启；**HTML 与预览不受影响**，点灰项也会说明原因 |
| 点 Word/PPT 报「WPS Office 服务已关闭」 | 去「MCP 服务」开启 `wps-office`；**预览不受影响**，可以继续看 |
| 「HTML」说没有服务端 HTML | 该回答不是教案 Agent 出的（服务端只在 B 出教案时落 HTML 页）；**改过内容则不需要它**——直接下改后的版本。或用 Word/PPT 落盘 |
| 找不到模板编辑器了 | 已按维护者要求移除（只要模板编辑能力不要了），**教案中心页面与编排台都还在**；导入 .docx 用教案中心的「导入 .docx」或面板里的【导入】 |
| 想导入自己的 .docx 来看 / 改 / 下载 | 面板里的【导入】或教案中心的「导入 .docx」（只进预览，不进模板库） |
| 改完的内容会丢吗 | 不会：改动存在内存 + `localStorage`（键带会话与标题），收起面板、切视图、刷新都在；点【下载▾】导出用的就是改后的内容 |
