# 教案模板：导入自有模板 + 全量编辑（v1.8.0）

教案中心支持老师**导入自己学校的 .docx 教案模板**，导入后可以改到每一段、
每一张表格和每一处格式，改完能**直接导出 Word/PPT**，也能**存成模板供 Agent B 生成教案时套用**。

> 与 `docs/04-WPS集成说明.md` 的分工：04 讲的是「WPS 能力接入与导出链路」，
> 本文讲的是「教案模板的导入与编辑」。两者通过导出链衔接（模板直出不走 WPS COM）。

## 1. 怎么用（教案中心 → 教案模板那一行）

| 按钮 | 作用 |
|---|---|
| **导入 .docx** | 选你自己的教案模板（Word）→ 解析成可编辑结构并进入**模板模式** |
| 模板下拉 + **载入编辑** | 载入已存模板；若是老式「骨架模板」（v1）会自动用 `orig/` 里的原件**升级成可编辑版** |
| **新建空白** | 从 6 个常用板块（目标/重难点/过程/板书/作业/反思）起手 |
| **保存为模板** | 存进 `content/templates/<id>.json`，并设为 **Agent B 当前模板** |
| 格式工具栏 | 选中文字改 **加粗/斜体/下划线/字体/字号/颜色**；对齐（左/中/右/两端）作用于光标所在段落 |
| **导出 Word / 生成 PPT** | 按当前编辑内容直出（复用教案中心的导出位置与「下载到本机」） |
| **退出模板模式** | 回到原来的「教案 × PPT 编排台」 |

模板模式内的编辑能力：

- **板块**：改标题文字（标题格式也能改）、设层级 H1–H4、上移/下移、新增/删除板块
- **段落**：直接改文字（所见即所得）、在任意位置加段落、上下移、删除本段
- **表格**：单元格直接改字、加/减行、加/减列、删除整表
- 编辑中的内容会自动存一份草稿到浏览器（`localStorage: edu_tpl_work_v2`），刷新不丢

## 2. 数据模型（`content/templates/<id>.json`，`spec_version: 2`）

```json
{
  "spec_version": 2, "template_id": "...", "name": "...", "source": "orig/<id>.docx",
  "updated_at": "2026-09-11T21:40:00",
  "blocks": [{
    "id": "b1", "kind": "section", "level": 1, "title": "一、教学目标",
    "title_align": "center",
    "title_runs": [{"text": "一、教学目标", "b": true, "font": "黑体", "size": 14}],
    "elements": [
      {"id": "e1", "type": "para", "text": "…", "align": "left", "line_spacing": 1.5,
       "runs": [{"text": "知识与技能：", "b": true}, {"text": "理解函数的概念", "i": true,
                 "size": 14, "color": "#DC2626"}]},
      {"id": "e2", "type": "table", "header": true,
       "cells": [[{"text": "环节", "b": true, "align": "center"}]]},
      {"id": "e3", "type": "image", "alt": "图片（导入不保留，导出会跳过）"}
    ]}]
}
```

- **块级**：板块顺序/层级/标题（含标题自身格式）、段落对齐与行距、表格行列表头
- **字符级**：逐 run 的加粗/斜体/下划线/字体（中文字体走 `eastAsia`）/字号/颜色
- 模板文件**与 Agent B 共用**：`template_spec.get_template()` 读到 v2 会调用
  `template_rich.derive_simple()` 派生 `{order,type,title,note}` 骨架，
  所以 `list_templates()` 里只有一个模板列表，Agent B 生成教案时直接套用户导入的板块顺序与名称。

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/template/import` | 上传 `.docx` → 返回富模型（**先不落盘**，供编辑） |
| POST | `/api/template/upgrade` | 把 v1 骨架模板用 `orig/<id>.docx` 升级成富模型 |
| GET | `/api/template/rich?id=` | 读富模板（编辑器载入） |
| POST | `/api/template/rich/save` | 保存编辑结果（`{template, set_current}`） |
| GET | `/api/template/blank?name=` | 空白富模板 |
| POST | `/api/wps/export` | 加 `template` 字段即按模板直出（`kind=docx|pptx`、`outDir`、`open`） |

## 4. 实现要点

- **解析**（`template_rich.docx_to_rich`）：按 body 顺序遍历段落与表格；
  标题判定比 `template_spec._looks_heading` **更严格**（样式命中 > 短编号行 > 全加粗短行 >
  关键词精确/短前缀命中），宁少判也不把整句正文当板块名。
- **编辑**：段落用 `contenteditable`，格式工具栏走 `document.execCommand`
  （`styleWithCSS` 开内联样式；字号用「`fontSize=7` 再替换成 `span`」的经典做法）。
- **回写**：保存时把 DOM 逐节点还原成 runs（读 `fontWeight/fontStyle/textDecoration/
  fontFamily/fontSize/color` 与 `b/i/u/font` 标签），表格逐格读 `textContent` 与对齐。
- **导出**：`docx_from_rich()` 用 python-docx 逐 run 还原（含 `w:rFonts eastAsia` 中文字体、
  `Table Grid` 表格、对齐与行距）；`pptx_from_rich()` 一个板块一页。
  **不走 WPS COM**——这一步是纯本地生成，因此不受 WPS 会话「幽灵态」影响。

## 5. 边界（先说清楚）

1. **图片不保留**：导入时图片位置会变成占位标记，导出时跳过并在返回值里报
   `images_skipped`（本项目范围不含图片重排）。
2. **页眉/页脚/分页符/复杂版式不解析**：只做正文的板块-段落-表格结构。
3. **字符级格式以 run 为粒度**：Word 里同一段内混排的格式会保留；
   在编辑器里改动文字后，该段若重新输入则按你设置的格式走。
4. **模板 id 取自文件名**（特殊字符转 `_`）；同名导入会覆盖同 id 模板。
5. 前端用到 `document.execCommand`（已废弃但各浏览器仍支持）；若某天失效，
   **文字编辑、板块/表格操作、保存与导出都不受影响**，只是工具栏的字符格式按钮会无效。

## 6. 实测记录（2026-09-11）

- 用仓库自带的真实模板 `content/templates/orig/高中数学_函数的概念_教案.docx` 全链路实测：
  - 导入 → **12 板块 / 18 段 / 6 表 / 1460 字**；板块标题格式保真（`黑体 14 加粗`）
  - 长句「教学重点：理解函数的概念，掌握…」**不再**被误判成板块标题（严格判标题的收益）
  - 保存后读回：板块/段落/表格与原意一致，`title_runs` 格式完整
  - 导出：Word 18 段 6 表（`黑体`×12、加粗×40）、PPT **13 页**，都是真 OOXML（头 `504b`）
  - Agent B 视角：`get_template()` 派生 11~12 个板块，`template_sketch()` 正常输出
- 浏览器侧（jsdom 真 DOM 回归）：导入 12 板块渲染、改标题/段落/单元格、
  加段落/加表格/加列/板块下移/删板块、保存（未保存标记消失）、导出 Word（结果条 + 下载链接），
  **全程零运行时错误**。
- 离线测试：`tests/test_template_rich.py` **13 例**（解析/格式保真/表格/规范化/派生/导出往返/桥接），
  全量 `unittest discover -s tests` 共 **143 例全绿**。
